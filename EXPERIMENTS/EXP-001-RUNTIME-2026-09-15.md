# EXP-001 Runtime Evidence — 2026-09-15

## Status

**CONFIRMED** — controlled Android runtime, native bridge, renderer, GPU frame rendering, and frame presentation.

## Test Target

Controlled Render Target Android ARM64 test application:

- Package: `com.pvr.controlledrendertarget`
- Device: Android 13 / ARM64
- Runtime process PID observed: `24351`
- Render thread TID observed: `24382`

## Runtime Evidence

The corrected APK was installed and launched on the Android device. The captured log shows a sustained native render loop:

```text
PVR-RenderTarget: FRAME_BEGIN frame=2658 pid=24351 tid=24382
PVR-RenderTarget: FRAME_RENDERED frame=2658
PVR-RenderTarget: FRAME_PRESENT frame=2658
...
PVR-RenderTarget: FRAME_BEGIN frame=2726 pid=24351 tid=24382
PVR-RenderTarget: FRAME_RENDERED frame=2726
PVR-RenderTarget: FRAME_PRESENT frame=2726
PVR-RenderTarget: RENDER_THREAD_STOP
```

Frames 2658 through 2726 were observed with the expected BEGIN → RENDERED → PRESENT sequence. The render thread subsequently stopped normally.

## What This Confirms

1. The Android application successfully reaches the native renderer path.
2. The renderer runs on a dedicated native thread.
3. The render loop executes repeatedly rather than only initializing once.
4. Frames reach the rendered stage.
5. Frames reach the presentation stage.
6. The controlled renderer can operate for a sustained sequence of frames on the test device.

## Evidence Boundary

This is a **controlled render-target experiment**. It does **not** demonstrate loading the bridge into the retail Minecraft process, accessing Minecraft's renderer, modifying Minecraft's rendering pipeline, or replacing RenderDragon.

The Minecraft target remains a separate, untested integration boundary. No claim of Minecraft renderer integration is made by this evidence.

## EXP-001 Conclusion

The controlled runtime portion of EXP-001 is **CONFIRMED**. EXP-001 can now be considered complete at the controlled native-loading/rendering checkpoint. Further work must be tracked as a new experiment and must not be represented as already proven by this result.
